# Hypertime

**Where reality branches can be ordered without borrowing a clock from
outside them.** Hypertime studies declared order and branching among
reality presentations. It is the second proposed display axis in Tyler Roost
/ The TimeLord's view of universempiternality as base realities arranged
like **hyperpheres** in an apparent grid. This is [HYPER], not an observed
cosmic map or a universal time coordinate.

The [field specification](FIELD_SPEC.md) defines a finite, dimensionless
index and explicit advances. Equal indices do not identify two branches;
different indices do not create a path. The [Python frame](hypertime.py) and
[tests](tests/test_contract.py) exercise those failures. The proposed
[Hyperspace join](https://github.com/TimeLordRaps/hyperspace/blob/main/GRID_SEAM.md)
pairs this axis with placement/observation by stable identity. It does not
make an atemporal realm age, or imply causality or time travel.

[FIELD.json](FIELD.json) is a local integration descriptor, not a Verifier
Standard (VSTD) certificate; VSTD concerns bounded computational-claim
evidence and has no physical unit. Run `python -u validate.py` for the
streamed standard-library suite under a 20-second overall deadline. The
runner has no per-test process isolation or automatic stuck-test stack dump.

[handoff](AGENT_HANDOFF.md) for the unproved boundaries.
